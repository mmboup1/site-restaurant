# Projet : site exemple pour un restaurant (portfolio)

## Le but du projet
- Ce site est un **exemple** pour montrer mon travail à de futurs clients (commerces de Poitiers).
- Le restaurant est **inventé** : "Le Petit Baobab", restaurant africain à Poitiers.
- Toutes les informations sont fausses (adresse, téléphone, prix). Ne jamais utiliser le nom,
  le logo ou les photos d'un vrai commerce.
- Plus tard, ce site servira de **modèle** : je changerai les textes, les couleurs et les photos
  pour chaque vrai client.

## Informations du restaurant (inventées)
- Nom : Le Petit Baobab
- Type : restaurant africain (cuisine sénégalaise), sur place et à emporter
- Adresse : 12 rue Exemple, 86000 Poitiers
- Téléphone : 05 00 00 00 00
- Horaires : mardi au samedi, 12h-14h30 et 19h-22h30 ; fermé dimanche et lundi
- Plats : thiéboudienne, yassa poulet, mafé, pastels, bissap, gingembre

## Règles techniques
- HTML, CSS et JavaScript simples, **sans framework** (pas de React, pas de Bootstrap).
- Le site doit bien s'afficher **sur téléphone d'abord**, puis sur ordinateur.
- Un seul fichier CSS (`css/style.css`) et un seul fichier JavaScript (`js/main.js`).
- Organisation des dossiers :
  - `index.html` (accueil), `menu.html`, `contact.html`
  - `css/`, `js/`, `images/`
- Utiliser des images libres de droits ou des images de remplacement (placeholder).
  Pas de photos trouvées sur Internet sans autorisation.
- Code propre et commenté **en français**.
- Pas de formulaire qui envoie des données : seulement des boutons "Appeler" (lien `tel:`)
  et "Itinéraire" (lien vers Google Maps).

## Style
- Couleurs : orange chaud, vert foncé et blanc cassé.
- Police lisible, gros boutons faciles à toucher sur téléphone.
- Style simple, chaleureux et moderne.
